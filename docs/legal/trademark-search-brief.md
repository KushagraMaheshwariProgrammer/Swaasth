# Trademark search brief — Swaasth / BillCheck

**Status:** Draft for a trademark attorney. Not a clearance opinion.  
**Date:** 12 August 2026

## Marks

| Mark | Use today | Notes |
|------|-----------|-------|
| **Swaasth** | Primary brand (app name, legal documents, Android `appName`, domain swaasth.in, package `swaasth.for.india`) | Common Hindi word (“health”) — inherently weak. |
| **BillCheck** | Former landing/UI brand; being retired from user-facing copy in favour of Swaasth | Descriptive of bill-checking. |

Android `applicationId`: `swaasth.for.india`. Namespace: `com.swaasth.billcheck` (legacy).

## Search request

Search the Indian Trade Marks Registry (public search / agent search) in:

- **Class 9** — downloadable software, mobile apps
- **Class 42** — SaaS, software as a service
- **Class 44** — medical / health services (even if we argue we are not a clinic)

For: Swaasth, Swasth, Swastha, Swaasth App, BillCheck, Bill Check, Bill-Check.

Also search domain and Play Store collisions.

## Recommended next steps (after search)

1. Keep **Swaasth** as the single primary mark.
2. File in 9/42 (and 44 if counsel so advises) before scaling ads.
3. Consider a distinctive logo/device mark because the word is weak.
4. Rename the Android namespace when convenient (`com.swaasth.billcheck` → `in.swaasth.app` or similar).
5. Do not spend on “BillCheck” advertising until the search is done; descriptive marks are hard to own.
